## 🚀 Proyectos destacados

### 🔥 Fenis — Backend de logística en microservicios

Backend de logística construido desde cero, aplicando la experiencia de haber operado un sistema similar en producción. Arquitectura de **microservicios en NestJS + TypeScript** (Gateway + Identity/Operations/Billing vía TCP), con PostgreSQL + Prisma y principios SOLID. Proyecto activo, en repo privado.

### 📸 Fotomercado — Marketplace de fotografía

Marketplace donde fotógrafos suben y venden fotos individuales por álbum, con **split automático de pagos vía Mercado Pago**. Backend en Fastify + PostgreSQL (Fly.io), frontend en Next.js 16 + Tailwind CSS, storage en Cloudflare R2. Proyecto activo, en repo privado.

### [🏋️ Tu Camino Fit](https://tucaminofitness.shop/)

Landing page de conversión para un entrenador personal, construida con **Angular 21** (Standalone Components) + Tailwind CSS, desplegada en Cloudflare Pages. Repo privado.

### [🎓 ERP para PyMEs — Trabajo Final (tesis)](https://github.com/LautiZ/TrabajoFinal-ERPPymes-Grupo148)

ERP web para PyMEs (inventario, POS y facturación) en equipo: backend en microservicios **NestJS + PostgreSQL + Prisma**, frontend en **Angular**.

### [⚙️ Taskrr](https://github.com/LautiZ/Taskrr_NestJS)

API REST construida con **NestJS**, autenticación **JWT** y despliegue con **Docker**.
